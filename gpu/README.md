# Spiking Algorithms on NVIDIA GPU

The SNN accelerator is responsible for the most intensive computing tasks: puck tracking and defense planning. The figure below shows a diagram of the pipeline. Puck tracking is performed by using three parallel spiking convolutional neural networks (F-SCNN, M-SCNN and S-SCNN, details follow) with a total of 89,376 neurons. Defense planning is achieved through an ad-hoc feed-forward mapping between two 2D layers of spiking neurons with a total of 29,792 neurons. The robot-paddle’s desired X- and Y-position are obtained by projecting the output of the ad-hoc mapping on both axes, using 357 neurons.  The SNN accelerator instantiates a total of 119,525 neurons. All the neurons are current-based leaky integrate-and-fire type (LIF).

## Puck Tracking
A spiking convolutional neural network (SCNN) combines the spatial feature extraction capabilities of convolutional neural networks with the event-driven processing paradigm of spiking neurons. This hybrid architecture effectively processes data characterized by temporal dynamics and sparsity, like those captured by event-based cameras. In this work, three SCNNs received events produced by the DVS as the puck moved in the playing area. Each SCNN produces activations for a different range of puck velocities. Specifically, F-SCNN was optimized for detecting rapid movements, S-SCNN was configured for very slow motions, and M-SCNN was tuned for transitions between these two extremes. To achieve this, we used a common kernel weight pattern with variations in the neuron’s membrane time constants (τ_m, Figure 1). For the F-SCNN, τ_m was hand-tuned to 1ms; for the M-SCNN, τ_m was set to 11ms; and for the S-SCNN, τ_m was set to 64ms. The rationale for these parameters is as follows: rapid puck-motion generates large amounts of spatially distributed events -> F-SCNN required a low time constant to (a) respond quickly and to (b) avoid creating blurred memory traces of the puck’s trajectory. Conversely, slow puck motion generates fewer, spatially clustered events  S-SCNN requires a higher time constant to accumulate and remember sufficient stimuli before activation.

## Defense Planning
Upon activation of the SCNNs, spikes are transmitted to the puck layer, which is subsequently connected to the paddle layer (red and orange in the figure). The puck layer integrates puck tracking information, while the paddle layer computes the defensive actions of the automated player. The paddle layer projects into two 1D 'layers' for X and Y positions.
